# Proyek Membangun CI/CD Pipeline dengan Jenkins

## 📌 Ringkasan Proyek
Dalam proyek ini, saya membangun **CI/CD Pipeline** menggunakan **Jenkins**, yang mencakup tahapan **Build, Test, Manual Approval, dan Deploy** secara otomatis. Selain itu, proyek ini juga menerapkan **monitoring pipeline dengan Prometheus dan Grafana**. 

## ✅ Kriteria yang Dipenuhi
- Menggunakan proyek yang telah dibuat sebelumnya.
- Menambahkan **Deploy Stage** dalam pipeline.
- Menjeda eksekusi pipeline pada **Deploy Stage** selama 1 menit.
- Menambahkan **Manual Approval Stage** sebelum tahap deploy.
- Memonitor Jenkins Pipeline menggunakan **Prometheus dan Grafana**.
